# Task Manager (Laravel)

A Laravel-based task management system designed for efficient personal or team productivity. This project demonstrates structured coding practices using the MVC architecture and Laravel’s robust features.

> **Note:** This repository is intended for **code reference and learning purposes only**.  
> **Cloning, forking, or downloading is not permitted.**  
> Please do not reuse the code in personal or commercial projects without explicit permission.

## Key Features

- User registration and login
- Create, view, update, and delete tasks
- Blade templating engine
- MVC architecture using Laravel
- Light/Dark mode toggle with persistence

## Technologies Used

- **Framework:** Laravel
- **Backend:** PHP (8.x)
- **Frontend:** Blade, Bootstrap/Tailwind (update accordingly)
- **Database:** MySQL

## Usage

To explore how the application is structured and how Laravel features are implemented:

- Browse through the `routes`, `controllers`, `models`, and `views` folders
- Check out Laravel's built-in functionalities like routing, middleware, and validation
- Observe clean code practices and MVC separation
